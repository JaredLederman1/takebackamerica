ARTWORK
Final production assets preserve the source flag silhouette, distressed texture, serif wordmark and tagline. Lower stripes are blue on the left and red immediately to the right of the fold. Cream background was removed; lower-stripe blue bleed was recolored. The horizontal version repositions existing artwork without replacing the lettering. The reversed version changes lettering and rules to cream.

Source: Media Platform Concept conversation, latest retrieved generated-image.png (1536 x 1024).
An imagegen transparent-export attempt was rejected because it baked in a checkerboard and altered details. Delivered assets instead use direct source extraction, color cleanup and deterministic exports.

SIZE / USAGE
Files labeled 4096w-upscaled are enlarged raster assets, not vector artwork or newly recovered detail. Keep aspect ratios locked. Use the flag alone for small icons; full-logo tagline is best at 600 px wide or larger. At 16 px the distressed texture naturally resolves into a simple four-stripe flag.
Cream background: #FAF7F0. Navy background: #061D30.
Transparent variants have actual alpha channels. On dark surfaces use the reversed logo.
