# Supplied brand assets

`take-back-america-media-package.zip` is the original, unmodified media package supplied by the owner. It includes every master, transparent export, wordmark, social avatar, favicon, source image, and its original documentation. `PACKAGE-README.txt` and `asset-manifest.json` are copies of the included documentation for easy browsing.

The website uses unmodified transparent PNG exports in `public/brand`:

- Header: `04-horizontal/tba-horizontal-transparent-1200w.png`
- Hero: `01-full-logo/tba-full-transparent-1600w.png`
- Dark footer: `05-dark-background/tba-full-reversed-transparent-1600w.png`
- Browser and Apple icons: supplied `07-favicons` exports in `app/`.

The original source image and upscaled masters remain in the archive, not in the public web directory. `logo-workshop/` preserves the earlier exploratory concepts for historical reference; those are not the website's active branding.
